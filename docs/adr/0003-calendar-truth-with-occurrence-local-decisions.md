# Calendar truth with occurrence-local decisions

Google Calendar remains authoritative for acceptance, cancellation, rescheduling, timing, and meeting links, but explicit app actions such as Dismiss and Handled persist for the current occurrence without changing the RSVP. Those local decisions can be restored; when an occurrence is rescheduled, protection resets as a fresh decision. This preserves calendar integrity while preventing routine synchronization from resurrecting a deliberate user choice.
