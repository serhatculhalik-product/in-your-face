# Domain Docs

This is a single-context repository.

## Before exploring

- Read `CONTEXT.md` at the repo root.
- Read ADRs under `docs/adr/` that touch the area being explored.
- Use the glossary vocabulary from `CONTEXT.md` in issues, specs, tests, and proposals.
- If an output conflicts with an ADR, surface the conflict explicitly instead of silently overriding it.
